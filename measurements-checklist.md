# Measurement verification checklist

Fill in "Actual" for each row, then hand this back so the design/geometry.js
can be checked against reality. The whole fit is built on the opening's
inside-casing width equaling stiles + KALLAX widths with **zero slack**:

```
0.75(gap) + 0.75(stile) + 43.875(4x3) + 0.75(center stile) + 57.875(4x4) + 0.75(stile) + 0.75(gap) = 105.5"
```

Any of the numbers below being off by even 1/8"–1/2" from what's assumed can
break that fit, so measure the actual worst case, not a best-case or average.
